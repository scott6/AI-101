# AI 101 Training
# README - How to Use the Prompting Exercises

## Overview

This workshop is designed to help participants understand how to interact effectively with Generative AI tools such as Microsoft Copilot, ChatGPT, Gemini, Claude, and similar AI assistants.

The workshop focuses on four fundamental concepts:

1. Conversation Memory (Context)
2. Prompt Structure
   - Role
   - Goal
   - Constraint
   - Output Format
3. Perspective-based Prompting
4. No-Shot, One-Shot, and Few-Shot Prompting

By the end of the session, participants should understand that:

```text
Better prompts produce better results.
```
